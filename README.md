# Tidepool · 美西行程 2026

旅行途中使用的小型 PWA，GitHub Pages 静态发布，无服务器或账户系统。

- **今天**：行程所在地日期、下一站、导航、完成 / 跳过 / 撤销、当天条件与相关待办。
- **行程**：17 天总览及日历导出，保留原来的区域色和卡片风格。
- **地图**：一个 Leaflet 实例，按地区 / 日期过滤，地点卡与今天页共享状态。
- **更多**：航班租车、装备、待办、离线、仅本机私人详情、信息来源。

## 数据与页面

`data/trip.js` 保存行程摘要、航班租车、装备及待办。`data/plans.js` 保存带稳定 ID 的每日站点、分类、时间约束和拍摄提示。四个地区文件保存路线几何与地点参考；`data/photos.js` 保留图片署名。

修改当天行程只需编辑 `plans`，总览与日历由同一套站点自动生成；更换地点时检查地区路线。站点 ID 不随排序变化。`styles.css` 管理外观；`app.js` 管理界面与本机状态；`maps.js`、`conditions.js`、`offline.js` 各自管理地图、条件和缓存。

`core.js` 中的日期、下一站和日历规则可独立测试：

```sh
node --test tests/*.test.cjs
```

本地预览：`python3 -m http.server 8765`。部署后等待 Pages workflow 成功，并核对页面版本。

## 时间与条件

旅行中以 America/Los_Angeles 为主；出境和返程按对应时区显示。历史日期不显示实时迟到，时间流逝不会自动将地点标记完成。可选 / 有空再去 / 雨备站不阻挡核心路线，可以主动选择“从这一站继续”。

Open-Meteo 提供选定日期地点的天气与日落，显示获取时间，失败时明确使用缓存或无数据。超过预报范围不伪造天气。潮汐通过当地潮表入口手动核对和记录；路况、营业与停车通过官方入口核对。时间表中的车程为计划预留，实时交通由导航应用提供。

## 离线

`sw.js` 按版本原子缓存应用文件；发版修改 VERSION。旧 `tp-*` 缓存会在激活时清理。地区按钮缓存照片，不批量抓取第三方地图。地图仅缓存已浏览的瓦片（最多 240 张），不宣称完整地区离线。天气服务和外部导航仍需网络。

## 私人详情

公开页面不保存私人住宅地址、预订确认号、订单号、票号或 PIN。旧 `booking.html` 仅跳转新版。用户可从自己的备份导入：

```json
{"version":1,"entries":[{"date":"2026-09-29","title":"住宿详情","details":"由用户在本机提供"}]}
```

导入由 File API 本地读取，不发送到服务器，内容按纯文本转义后显示。存储在当前浏览器 localStorage，未加密；可导出备份或清除。不要在共享设备导入。过去已经公开的 Git 历史不因删除当前文件而消失；站点仍是公开行程，`noindex` 不是访问控制。

原有装备键 `us-trip-pack-v1` 保留。其它状态键有独立版本，均限当前浏览器。
